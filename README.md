# Factory

**Factory** is a Qt6 graphical application to gather your favorites tools used to build applications.


## Available variables
These variables names are available for customizing the `factory.xml` file :
* `%FILE%`
* `%FILE_NAME%`
* `%FILE_FOLDER%`
* `%PROJECT%`
* `%LANGUAGE%`
* `%TOOLKIT%`
* `%YEAR%`
* `%MONTH%`
* `%DAY%`
* `%TIME%`
* `%DATE%`
* `%DATETIME%`
* `%AUTHOR%`
* `%COMPANY%`
* `%MAIL%`
* `%WEB%`
* `%DOC_FOLDER%`

The values are taken from the settings or dynamically computed.
